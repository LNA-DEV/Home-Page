{{- /* gallery-meta.html Returns metadata from data/gallery.yaml as two lookup dicts sharing the same entries: .bySrc — keyed by filename (matches path.Base of $image.Name from global resources) .byId — keyed by UUID id (used by featured_image and other id-based lookups) Use with partialCached for O(1) builds after first call. Every entry gains two derived keys: `.projects` — the `project:` field normalised to a slice, so a photo can sit in several albums (`project: [a, b]`) while the plain string form keeps working. Filter with `in $meta.projects $slug` — never compare `.project` directly, and never use `in` on the raw field, which would match a substring ("eagles" against "eagles-2026") instead of a whole slug. `.models` — the same normalisation for `model:`, the slug(s) of the people in the photo (data/models.yaml). Same rule: filter with `in $meta.models $slug`. `.title`, `.alt`, `.description` — normalised IN PLACE from string-or-map to a `{en, de, sv}` map, so a reader only ever has to handle one shape. A bare string means English; `title: Foo` and `title: {en: Foo}` are the same entry. They are NOT resolved to one language here — head.html, resolve-featured-image.html and feed/list.html all want the raw maps, and collect-images.html does the pick for the templates that render prose. Never print one of the three directly — you would get a Go map literal. `.slug` — the per-photo page URL segment, PER LANGUAGE: slug = urlize( entry.slug || title[lang] || title.en ) This partial is `partialCached` with no variant key, which is fine and is why the slug may depend on the language at all: Hugo keeps that cache per language Site, so the partial is evaluated once per language and each build sees its own value (verified on 0.166 — a no-variant partial returning .Site.Language.Lang yields en/de/sv correctly). The context argument contributes nothing to the key; only variants do. An earlier version of this comment claimed the opposite and used it to argue the return value had to stay language-neutral. It does not. Deriving from the title rather than the filename is deliberate: 65% of the filenames are camera output ("DSC_2632", "P1017063"), which made for URLs no reader or search engine could use. The old objection — that prose lived in the image's XMP, outside the repo, so a darktable re-export would silently move a live URL — died with the one-time metadata import: titles live in data/gallery.yaml now and the build never looks at the file's XMP again. The cost is that a reworded title moves a URL. Two things absorb that: every page keeps its permanent /gallery/photo// alias, and `slugAliases:` below holds the URLs it used to have. Set an explicit `slug:` to pin one language- neutrally and opt out of the whole mechanism. `.slugAliases` — frozen former URL segments, normalised to a slice. Written once at the one-time filename→title migration and never recomputed; gallery-photo-pages.html emits each as a redirect, skipping any that equals the current language's slug. Hand-edit to preserve a URL after a rewording. Transliteration before `urlize`, which would otherwise percent-encode — "Skärgård" must not become "sk%C3%A4rg%C3%A5rd". The table is PER LANGUAGE: German expands the umlaut ("Porträt" → "portraet"), Swedish and English fold it away ("över" → "over"). See the table itself for why each is wrong in the other's language. Hard-fails if any entry is missing an id — run scripts/add-gallery-ids.py to fix — if an entry has no title in the current language and none in English, since it would then have no URL, or if two entries resolve to the same slug, which would make one page silently overwrite the other. Also hard-fails on a `model:` slug that names no record in data/models.yaml, and on a record without a valid `visibility:` — see the block above the range for why a person is the one join that must not degrade to a warning. Usage: {{ $metaAll := partialCached "gallery-meta.html" . }} {{ $bySrc := $metaAll.bySrc }} {{ $meta := index $bySrc "My Image.JPG" }} */ -}} {{- $bySrc := dict -}} {{- $byId := dict -}} {{- $seenSlugs := dict -}} {{- /* Hugo scopes the partialCached store per language Site — verified on 0.166: a partial cached with NO variant key still returns the current language's value in each of the three builds. So this runs once per language and the slug below may safely depend on it; $seenSlugs is per-language for free. */ -}} {{- $lang := site.Language.Lang -}} {{- /* Characters urlize would percent-encode rather than fold — "Skärgård" must not become "sk%C3%A4rg%C3%A5rd". The table is PER LANGUAGE, because the two conventions genuinely differ and each is wrong in the other's language. German expands the umlaut, which is what a German keyboard-less speller does and what DIN 5007-2 codifies: "Porträt" → "portraet", "grünen" → "gruenen", "weißen" → "weissen". Swedish does not: ä ö å are letters in their own right, not decorated vowels, so the ASCII fallback drops the ring and the dots — "över" → "over". English has no native diacritics and folds the same way for the handful of borrowed names it carries ("Ardèche" → "ardeche", "Öland" → "oland"). Verified across all 648 photos with both tables in place: zero collisions in any of the three languages, so neither the expansion nor the folding costs a URL here. Expansion can only ever reduce collisions; folding is the one that could in principle merge two titles, and does not. */ -}} {{- /* Written out in full rather than composed from a shared tail: `append` on a slice of slices appends the inner slice as one element, and the two tails are ten pairs. Keep the trailing block identical in both. */ -}} {{- $translit := slice -}} {{- if eq $lang "de" -}} {{- $translit = slice (slice "ä" "ae") (slice "ö" "oe") (slice "ü" "ue") (slice "Ä" "Ae") (slice "Ö" "Oe") (slice "Ü" "Ue") (slice "æ" "ae") (slice "Æ" "Ae") (slice "ø" "oe") (slice "Ø" "Oe") (slice "å" "a") (slice "Å" "A") (slice "ß" "ss") (slice "é" "e") (slice "è" "e") (slice "ê" "e") (slice "á" "a") (slice "à" "a") (slice "í" "i") (slice "ó" "o") (slice "ú" "u") (slice "ñ" "n") (slice "ç" "c") -}} {{- else -}} {{- $translit = slice (slice "ä" "a") (slice "ö" "o") (slice "å" "a") (slice "Ä" "A") (slice "Ö" "O") (slice "Å" "A") (slice "ü" "u") (slice "Ü" "U") (slice "ß" "ss") (slice "æ" "a") (slice "Æ" "A") (slice "ø" "o") (slice "Ø" "O") (slice "é" "e") (slice "è" "e") (slice "ê" "e") (slice "á" "a") (slice "à" "a") (slice "í" "i") (slice "ó" "o") (slice "ú" "u") (slice "ñ" "n") (slice "ç" "c") -}} {{- end -}} {{- /* The closed set of model slugs, validated once. Unlike `species:`, an unknown `model:` is an ERROR rather than a warning: the slugs are a small set the author invented himself, so a miss is always a typo — and the cost of a silent miss is a person losing the credit or the visibility setting they agreed to. A record is therefore also required to state `visibility:` explicitly, with no default: consent is a decision somebody made, not something a template gets to assume. Deleting a record is NOT how a person is removed — the photos still carry the slug and this loop will stop the build, which is correct, because the photos themselves still need a decision. `visibility: hidden` is the tombstone. See data/models.yaml. */ -}} {{- $modelSlugs := dict -}} {{- $visibilities := slice "public" "unlisted" "hidden" -}} {{- range $record := (hugo.Data.models.models | default slice) -}} {{- /* printf, not the raw value: YAML resolves an unquoted `slug: 007` or `model: 2026` to an int, and both `dict true` and the `index` below then fail with an opaque Go type error instead of the message this loop exists to print. Normalising here makes every downstream `.models` entry a string too, so `in $meta.models $slug` keeps working. */ -}} {{- $mslug := printf "%v" ($record.slug | default "") -}} {{- if not $mslug -}} {{- errorf "data/models.yaml: a record has no `slug:`" -}} {{- else -}} {{- if index $modelSlugs $mslug -}} {{- errorf "data/models.yaml: duplicate slug %q — a slug is an identity and is never reused" $mslug -}} {{- end -}} {{- $vis := $record.visibility | default "" -}} {{- if not (in $visibilities $vis) -}} {{- errorf "data/models.yaml: model %q must set `visibility:` to one of public | unlisted | hidden (got %q)" $mslug $vis -}} {{- end -}} {{- /* `name:` is required for a record that renders, and deliberately NOT for a `hidden` one. This file is public on GitHub, history included, so a tombstone that still had to carry the name would take the name off the site and leave it in the repository forever — which is not what someone asking to be forgotten asked for. A hidden record may be `slug:` + `visibility:` and nothing else. */ -}} {{- if and (ne $vis "hidden") (not $record.name) -}} {{- errorf "data/models.yaml: model %q has no `name:` — the display name lives here and nowhere else (only a `hidden` record may omit it)" $mslug -}} {{- end -}} {{- $modelSlugs = merge $modelSlugs (dict $mslug true) -}} {{- end -}} {{- end -}} {{- range hugo.Data.gallery.images -}} {{- if not .id -}} {{- errorf "data/gallery.yaml: entry %q has no id (run scripts/add-gallery-ids.py)" .src -}} {{- end -}} {{- $projects := .project | default "" -}} {{- if not (reflect.IsSlice $projects) -}} {{- if $projects -}} {{- $projects = slice $projects -}} {{- else -}} {{- $projects = slice -}} {{- end -}} {{- end -}} {{- /* Captured before the `with` and the ranges below: inside those `.` is no longer this entry, and `$` is the partial's page context, not the entry either. */ -}} {{- $src := .src -}} {{- $models := .model | default "" -}} {{- if not (reflect.IsSlice $models) -}} {{- if $models -}} {{- $models = slice $models -}} {{- else -}} {{- $models = slice -}} {{- end -}} {{- end -}} {{- /* uniq, unlike .projects: a repeated slug on one photo would count the photo twice on that person's page and emit two caption spans for one name. A repeated project slug is harmless by comparison. printf for the same reason the record loop above uses it — an unquoted numeric slug. */ -}} {{- with $models -}} {{- $norm := slice -}} {{- range . }}{{ $norm = $norm | append (printf "%v" .) }}{{ end -}} {{- $models = uniq $norm -}} {{- end -}} {{- range $mslug := $models -}} {{- if not (index $modelSlugs $mslug) -}} {{- errorf "data/gallery.yaml: photo %q names model %q, which is not a slug in data/models.yaml" $src $mslug -}} {{- end -}} {{- end -}} {{- /* The title in THIS language, falling back to English — the same rule the prose fields use below, resolved early because the slug needs it before the normalisation block runs. `title:` is string-or-map at this point. */ -}} {{- $rawTitle := index . "title" -}} {{- $titleHere := "" -}} {{- if reflect.IsMap $rawTitle -}} {{- $titleHere = or (index $rawTitle $lang) (index $rawTitle "en") "" -}} {{- else -}} {{- $titleHere = $rawTitle | default "" -}} {{- end -}} {{- /* printf, not the raw value: an unquoted `slug: 007` is an int in YAML and would urlize to "7". */ -}} {{- $slug := printf "%v" (.slug | default "") -}} {{- if not $slug -}} {{- if not $titleHere -}} {{- errorf "data/gallery.yaml: entry %q (id %s) has no title in %q and none in en, so it has no URL — give it a title, or pin one with `slug:`" .src .id $lang -}} {{- end -}} {{- $slug = $titleHere -}} {{- end -}} {{- range $pair := $translit -}} {{- $slug = replace $slug (index $pair 0) (index $pair 1) -}} {{- end -}} {{- $slug = urlize $slug -}} {{- if not $slug -}} {{- errorf "data/gallery.yaml: entry %q (id %s) produced an empty slug in %q — its title is punctuation only; set `slug:` on it" .src .id $lang -}} {{- end -}} {{- with index $seenSlugs $slug -}} {{- errorf "data/gallery.yaml: %q and %q both resolve to the slug %q in %q — reword one title, or set an explicit `slug:` on one of them" . $src $slug $lang -}} {{- end -}} {{- $seenSlugs = merge $seenSlugs (dict $slug .src) -}} {{- /* Frozen former URLs, emitted as redirects by gallery-photo-pages.html. Written once at the filename→title migration and never recomputed: an alias exists to keep a dead URL alive, so it must NOT follow the thing that moved. urlize defensively — the file is hand-editable. */ -}} {{- $aliases := slice -}} {{- range $a := (.slugAliases | default slice) -}} {{- $a = urlize (printf "%v" $a) -}} {{- if $a -}}{{- $aliases = $aliases | append $a -}}{{- end -}} {{- end -}} {{- /* Prose fields: string-or-map in, map out. `.` is rebound by the inner range and `$` is the partial's page context, so the entry is captured first. In `merge a b` the right-hand map wins, which is what replaces the raw string with the normalised map below. */ -}} {{- $entryRaw := . -}} {{- $prose := dict -}} {{- range $key := (slice "title" "alt" "description") -}} {{- $val := index $entryRaw $key -}} {{- if reflect.IsMap $val -}} {{- $prose = merge $prose (dict $key $val) -}} {{- else -}} {{- $prose = merge $prose (dict $key (dict "en" ($val | default ""))) -}} {{- end -}} {{- end -}} {{- $entry := merge . (dict "projects" $projects "models" $models "slug" $slug "slugAliases" $aliases) -}} {{- $entry = merge $entry $prose -}} {{- $bySrc = merge $bySrc (dict .src $entry) -}} {{- $byId = merge $byId (dict .id $entry) -}} {{- end -}} {{- return (dict "bySrc" $bySrc "byId" $byId) -}}

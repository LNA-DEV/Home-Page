{{- /* Does THIS page get the newsletter block in its post footer? Returns a boolean, and single.html and page.html both ask it — which is the whole point, since those two templates are near-duplicates and a rule written out twice is a rule that eventually disagrees with itself. head.html used to consult this as well, to decide whether to load newsletter.js. It no longer needs to: the header CTA put a form on every page, so the script is loaded unconditionally. Should that CTA ever go away, head.html will want this predicate back. Three conditions, all of which must hold: 1. It is a single page. Lists, the home page and taxonomy terms render through list.html, which has no post footer at all. 2. It is not one of the gallery/dex themes. single.html and page.html dispatch those to their own partials before ever reaching the post-single branch, so a footer block would simply never appear. NOTE: this list mirrors the dispatch in those two templates. Adding a theme there means adding it here, or the script gets loaded on a page that has no form -- harmless, but it is the kind of drift worth catching early. The reverse direction cannot happen: an unknown theme falls through to the post-single branch, and so does this list. 3. The page has not opted out with `hideNewsletter: true` in its front matter. That flag is the ONLY way to suppress the block. This used to also bail out on `.HasShortcode "newsletter"`, so that a post embedding {{ "{{< newsletter >}}" }} in its body did not end up carrying the form twice. Removed on purpose: it meant a shortcode in the body silently switched off an unrelated block further down the page, which is invisible at both call sites -- nothing in the post says it, and nothing in the footer does either. An author who wants only the inline one now says so with `hideNewsletter: true`, which reads as what it is. The cost is that the combination is no longer prevented for you: a post with the shortcode and no flag shows both. */ -}} {{- $galleryThemes := slice "gallery-portfolio" "gallery-page" "gallery-page-hidden" "gallery-archive" "gallery-project" "dex-species" -}} {{- $show := true -}} {{- if ne .Kind "page" -}} {{- $show = false -}} {{- else if in $galleryThemes (.Params.Theme | default "") -}} {{- $show = false -}} {{- else if .Param "hideNewsletter" -}} {{- $show = false -}} {{- end -}} {{- return $show -}}

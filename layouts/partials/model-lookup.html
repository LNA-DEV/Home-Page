{{- /* model-lookup.html Model slug -> the model's page, for naming and linking a person on a photo. Returns a dict keyed by slug: { "jane-doe": { "slug": "jane-doe", "name": "Jane Doe", "url": "/de/gallery/models/jane-doe/", "permalink": "https://lna-dev.net/de/gallery/models/jane-doe/", "visibility": "public", "autotag": false, "profiles": [{"platform": "instagram", "url": "https://…"}] } } `url`, `name` and `visibility` are what a caption needs. `permalink`, `autotag` and `profiles` exist for the gallery feed (rss.xml), which hands the autouploader in HomePageCompanion everything it needs to tag a person — and which filters to `public` itself, because a feed is a listing. `autotag` is a bool and true ONLY for a literal YAML `autotag: true`: anything else, a string "true" included, reads as no consent (gallery-meta.html stops the build on a non-bool). `profiles` is `links:` with the icon key lowercased into `platform`. Deliberately NOT model-index.html: that partial joins every record against every gallery photo, and a caption needs a name and a URL. gallery.html renders on every grid, every album, every dex species page and every photo page, so making it depend on the whole-gallery collection for one string would be the same mistake dex-lookup.html exists to avoid. THE ABSENCE OF AN ENTRY MEANS PRINT NOTHING. This is the one place it differs from dex-lookup.html, where a species the dex does not know still gets its scientific name printed as plain text. A person's name appears on this site only through a record that is published — so a `hidden` record, a record whose page was not generated (no non-archive photos), and a slug this lookup has never heard of all render as no row at all. The slug is never a fallback for the name, and the caller must not invent one. `unlisted` records ARE in here: their page is rendered and reachable, it is just not listed or indexed, and the photos that link to it are indexed anyway. The URL comes from site.GetPage rather than being assembled by hand, so the link survives the section moving — and a record whose page does not exist yields no entry, which is exactly the behaviour above. Call via partialCached with the language as the variant: {{ partialCached "model-lookup.html" (dict "lang" $lang) $lang }} */ -}} {{- $out := newScratch -}} {{- range $record := (hugo.Data.models.models | default slice) -}} {{- /* ALLOWLIST — see the same note in model-index.html. `ne "hidden"` would publish a name on every photo caption the moment `visibility:` is misspelled, and errorf does not stop the build from writing those files. */ -}} {{- if and $record.slug $record.name (in (slice "public" "unlisted") ($record.visibility | default "")) -}} {{- $autotag := and (eq (printf "%T" $record.autotag) "bool") $record.autotag -}} {{- $profiles := slice -}} {{- range $l := ($record.links | default slice) -}} {{- $platform := lower (printf "%v" ($l.name | default "")) -}} {{- $u := trim (printf "%v" ($l.url | default "")) " " -}} {{- if and $platform $u -}} {{- $profiles = $profiles | append (dict "platform" $platform "url" $u) -}} {{- end -}} {{- end -}} {{- with site.GetPage (printf "/gallery/models/%s" $record.slug) -}} {{- $out.SetInMap "m" $record.slug (dict "slug" $record.slug "name" $record.name "url" .RelPermalink "permalink" .Permalink "visibility" $record.visibility "autotag" $autotag "profiles" $profiles ) -}} {{- end -}} {{- end -}} {{- end -}} {{- return ($out.Get "m" | default dict) -}}

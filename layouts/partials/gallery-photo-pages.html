{{- /* Content adapter: one page per gallery photo. All three languages, always — the same call the dex makes. `title`, `alt` and `description` are {en, de, sv} maps in data/gallery.yaml now, each falling back to English, so a German page with English prose is a German page whose prose has not been written yet, not a duplicate: Hugo links the three through `translationKey`, head.html and sitemap.xml emit the hreflang cluster on their own, and Google reads such a cluster as alternates. Generating a page only once a translation exists would instead send a /de/ visitor to /en/ for most photos. There is one adapter file per language because Hugo scopes an adapter to the language of its filename — a bare _content.gotmpl produces English pages only. The slug is derived from the title and is therefore PER LANGUAGE: the three no longer share a URL segment, and `translationKey` is what ties them together. Every photo gets a page, archive included: only four of 648 carry no title, no alt, no species and no tags, which is far too few to justify a threshold. `aliases` is a TOP-LEVEL key of AddPage, not a param (verified on Hugo 0.166). It emits a redirect page carrying rel=canonical back to the slug URL, which is what makes /gallery/photo// a permanent address: the slug follows the title and can move, the id never does. The frozen former slugs in `.SlugAliases` ride along the same mechanism — see gallery-meta.html. */ -}} {{- $lang := .Site.Language.Lang -}} {{- $c := partialCached "gallery-collected.html" . $lang -}} {{- range $c.all -}} {{- /* The heading is the title, never the alt text. Every photo has one — gallery-meta.html stops the build otherwise. */ -}} {{- $title := .Title -}} {{- /* The meta description and the search index want the story where there is one and the alt text where there is not — which is exactly what .Description resolves to (collect-images.html falls it back to .Alt). */ -}} {{- /* The permanent id address, plus every URL this photo used to live at. A former slug that equals THIS language's current slug is skipped: it is not an alias, it is the page, and aliasing a page to itself makes Hugo write a redirect over the page it redirects to. That happens whenever a photo's title in one language reproduces its old filename, so the filter is load-bearing rather than defensive. */ -}} {{- $slug := .Slug -}} {{- $aliases := slice (printf "/gallery/photo/%s/" .Id) -}} {{- range $former := (.SlugAliases | default slice) -}} {{- if ne $former $slug -}} {{- $aliases = $aliases | append (printf "/gallery/photo/%s/" $former) -}} {{- end -}} {{- end -}} {{- /* `translationKey` is TOP LEVEL, not a param: it is a front-matter key of .AddPage, the same shape as `aliases` and `build`. Inside `params` Hugo ignores it and falls back to pairing translations by path — invisible on the dex and model adapters, whose slug is language-neutral, and silently wrong here, where the three languages have three different slugs. It left all 648 photos in all three languages with no hreflang cluster at all. */}} {{- /* The photo's tags as `phototags` terms — one page per tag under /gallery/tags/ (docs/concepts/tag-pages.md §4). Three things are load-bearing: - they go IN `params`. As a top-level key of .AddPage — where aliases, build and translationKey go — Hugo ignores them without a word. - the LOWERCASED .Tags, never the stored spelling: 12 tags are stored in two spellings across photos (naturePhotography / naturephotography), Hugo merges them into one term and titles it after whichever page it meets first. - none for an archive photo. A tag page is a slice of /gallery/general/, and the archive is where retired shots go. Its tags stay on its page as plain text. */ -}} {{- $phototags := slice -}} {{- if ne .Section "archive" -}}{{- $phototags = .Tags | default slice -}}{{- end -}} {{- $page := dict "path" .Slug "kind" "page" "title" $title "description" (or .Description $title | plainify | truncate 160) "content" (dict "mediaType" "text/markdown" "value" (.Description | default "")) "aliases" $aliases "translationKey" (printf "photo-%s" .Id) "params" (dict "theme" "gallery-photo" "photo_id" .Id "hideMeta" true "searchHidden" false "phototags" $phototags ) -}} {{- $.AddPage $page -}} {{- end -}}
